# Loco por el cielo

Página web desarrollada como parte del **Desafío 3 de Pledu**.

El proyecto está enfocado en la fotografía y contemplación del cielo, utilizando una presentación visual basada en imágenes para crear una experiencia simple y atractiva.

## Demo

[Ver proyecto online](https://pledu-desafio3.vercel.app/)

## Vista del proyecto

La página presenta una galería visual con diferentes imágenes del cielo y una sección de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Características

- Diseño visual centrado en imágenes.
- Galería de fotografías del cielo.
- Interfaz simple y minimalista.
- Diseño adaptable a diferentes tamaños de pantalla.
- Sección de contacto.
